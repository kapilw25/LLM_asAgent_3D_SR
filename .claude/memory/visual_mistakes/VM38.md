## VM38 — LaTeX figure PLACEMENT defects recurred ALL session because the visual audit was run ONCE, not as a per-edit gate (2026-08-01)

Unlike the plot-*authoring* VMs, these are `.tex` *placement* bugs that were each "fixed" then reintroduced on the very next edit of `arxiv_combined`:
- (a) figures jammed back-to-back with NO connective text (splitting a paired `figure*` into two touching `figure*`);
- (b) plot text unreadable because a sub-`\textwidth` include width shrank an already-small plot AND a BOLD/enlarged variant existed but was not used (density figure: shipped `denseworld_vs_west_density.png.pdf` instead of the readable `_bold.pdf` that v1 used — see feedback_embolden_dont_redraw);
- (c) a figure placed BEFORE `\begin{abstract}` (a `[t!]` float grabbed the column top and landed above the abstract);
- (d) a squarish plot naively set to `\textwidth` → half-page square.

**ROOT CAUSE**: the `visual-audit` agent was run ONCE on an early snapshot and then NOT re-run after each subsequent `.tex` edit, so every new placement defect sailed straight through to the user. The KB was also not consulted *before* touching a figure, so known per-figure needs (density → bold variant) were missed.

**Prevention — treat the audit as a PER-EDIT GATE, never one-shot.** After ANY `.tex` figure/layout edit, BEFORE presenting:
1. rebuild;
2. render EVERY changed page at ≥110 dpi;
3. READ the axis labels / ticks / legend to confirm legibility;
4. confirm connective text sits between every pair of consecutive figures and that no figure precedes the abstract;
5. before placing a figure, grep this KB + the `v1/figures/` dir for a `_bold` / `_text_enlarge` / `_merged` variant and use it.

A single audit pass is INSUFFICIENT. The `surface-visual-mistakes.sh` PreToolUse hook now injects the matching VM rows on every figure edit so this cannot silently recur.
